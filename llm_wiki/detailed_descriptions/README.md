# Detailed Descriptions

In-depth, technical explanations of **how the code and the repository work**. These are the
companions of the higher-level [`summaries/`](../summaries) : a summary tells you what a tool
does and how to use it, a detailed description explains how it is implemented.

Two kinds of file live here :

- **Per-tool deep-dives** — e.g. `autoresearch_config.md` (experiment management),
  `autoresearch_run.md` (`run` / `sync`).
- **Cross-cutting notes** — e.g. `shared_knowledge.md` (code shared across tools).
- **Per-tool status files** — `<tool>_status.md` (e.g. `autoresearch_status.md`) tracking
  what is implemented and what is still pending.

See [`../index.md`](../index.md) for the full, linked list.
